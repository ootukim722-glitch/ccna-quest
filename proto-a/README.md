# 試作A: 育てて・進化させて・そろえる(DS〜3DS本流の作り)

既存の「草むらでクイズ」の作りに対して、「手持ちを育てる」「進化する」「街と道路とジム」「画面構成の決まったバトル」を足した試作。1エリア(a1 はじまりの森、15体)だけ。完成度より、遊んで比べることが目的。

## 開き方
- ローカル: ccna-quest フォルダで `node tools/serve.js 8081` を起動して `http://localhost:8081/proto-a/index.html`
- 公開時: `/ccna-quest/proto-a/` で動く(読み込みは相対パスのみ。`../js/core.js` などの教材・復習・ドット絵・音を再利用)
- セーブは本番と別(`ccnaquest.protoA.v1`)。本番のデータは触らない。

## 遊び方(15〜20分の流れ)
1. ネットワーク村の赤い屋根(ハカセの家)へ入り、ハカセの説明を聞く。「ルーたん」か「ポチッチ」を1体もらう。
2. 北の1番道路へ。草むらで野生と戦い、勝つと仲間にできる。トレーナー(視線に入ると近づいてくる)が3人いて、2〜3体の連戦。
3. 仲間が6体そろったら、道路の北端のジムへ。ジムリーダー「ケーブルじい」に5問正解で勝ち、バッジ。
4. 疲れたら青い屋根の復習所へ。手持ちが全回復し、復習が必要な問題が3問以上たまっていると復習バトルを案内してくれる。

操作: 十字ボタン/矢印キーで移動、「はなす」/Enter で決定。メニューで手持ち・ずかん・ボックス。

## バトルの仕組み
- 画面: 上に相手(右上)と名前・Lv・HP、下に自分(左下・後ろ姿)とHP・経験値、黒枠のメッセージ窓。
- コマンド: たたかう / なかま(入れ替え) / ヒント / にげる。
- 「たたかう」で問題が出て、4つの選択肢が「わざ」の2x2ボタンになる。正解=技が当たる(自分のレベルが高いほどダメージ大、3連続正解で急所)。不正解=相手の反撃でHPが減る。解説は毎回出る。
- ヒントは用語のたとえ話を見せる。使った問題の経験値は半分。
- 経験値は正解のたびに入り、レベルが上がる。Lv8とLv16で進化(色・つの・かんむり・つばさが変わる)。進化はバトル後に演出つきで起きる。
- 全滅しても減点なし。復習所に戻って全回復。
- 正誤は毎回 `Q.record` で記録(既存の復習データ)。ずかんの「復習」印、復習所の案内、復習バトルがこれを使う。

## 試作で省いたもの
- a2〜a7 のエリア、複数のジム、もぎしけん、けいさんドリル。
- 技(わざ)の種類やタイプ相性。「わざ」は選択肢の見た目だけ。
- 道具、お金、持ち物。仲間にするときの成功率(かならず仲間になる)。
- 経験値の分配(戦った1体だけが得る)。なかまの入れ替えにはターン消費がない(学習優先)。
- 野生の再出現制限、昼夜、歩く住人、屋内の細かい家具の当たり判定の作り込み。
- ボックスは単純な一覧のみ(並べ替え・預ける先の指定なし)。
- BGMはエリア共通(既存の3曲を流用)。進化・レベルアップ・回復の効果音は試作側で追加。
- 小さな画面での細かい調整、PWA化、オフライン対応。

## 製品版にするときの課題
- 経験値とレベルの数字は仮置き(`PA.need` と `pa-battle.js`)。15体で足りる量か、エリアが増えたときの敵レベルの伸びを決める必要がある。
- ずかんの「おぼえ具合」(復習の箱)と、育成レベルが別々の数字になっている。どちらを主役にするか、統合するか決める。
- 手持ち6体のうち実際に使うのは先頭の1〜2体になりがち。全員に経験値を分ける、相性を入れるなどで「そろえる意味」を作る必要がある。
- 野生が仲間になる条件が「勝つこと」だけ。捕獲ものの緊張感を、学習とどう両立するか。
- 問題の難しさが敵のレベルと無関係。レベルが高い敵ほど tier の高い問題を出す、などの対応づけ。
- マップは手書きなので、エリアが7つ・ジムが7つになると作業量が大きい。ASCII+建物の定義を、データファイルに分けて量産しやすくする。
- 進化後の見た目はコード生成の飾り(つの・かんむり・つばさ)。最終的にはキャラごとに描き分けたい。
- バトルのメッセージが多く、1戦が長め(解説を毎回表示)。解説は間違えたときだけ詳しく出す、などの調整余地がある。
