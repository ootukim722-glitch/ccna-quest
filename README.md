# CCNAクエスト

CCNA(200-301 v1.1)をゲーム感覚で覚える、スマホ向けの学習RPG。自分専用・費用0円。

## あそびかた
- 草むら(濃い緑)を歩くとモンスター(=覚える用語)が出る。クイズに勝つと仲間になる。
- 先生(白い服の人)が、たとえ話で各エリアの導入を説明してくれる。
- 間違えても減点なし。間違えた問題は「ふくしゅうバトル」に出てくる。
- 各エリアのボスに勝つとバッジ。「もぎしけん」は出題分野の配点に合わせて出題。
- 「けいさんドリル」でサブネット計算を何度でも練習できる(問題は自動生成)。

## 開き方
- **PCで確認**: `index.html` をダブルクリック(サーバー不要)。
- **ホーム画面に追加(PWA)**: `node tools/serve.js` で起動するか、公開したURLをスマホで開いて「ホーム画面に追加」。

## 構成
| 場所 | 中身 |
|---|---|
| `packs/ccna/a1〜a7.js` | 教材データ(エリアごと)。モンスター・たとえ話・問題・解説 |
| `js/core.js` | 教材の登録、保存、復習(間隔反復)の仕組み |
| `js/sprites.js` | ドット絵(コードで描画。画像素材なし) |
| `js/audio.js` | 効果音とBGM(その場で合成。音声素材なし) |
| `js/gen.js` | サブネット計算ドリルの自動出題 |
| `js/maps.js` `js/world.js` | マップの自動生成と移動 |
| `js/battle.js` `js/quiz.js` `js/screens.js` | バトル、クイズ、メニュー各画面 |
| `docs/content-spec.md` | 教材データの書き方(問題を足すときの仕様) |

## 問題を足す・直す
`packs/ccna/` の該当ファイルを開き、`questions` に1問足すだけ。形式は `docs/content-spec.md`。
別の資格(基本情報など)は、`packs/<資格名>/` に教材を作り、`js/core.js` の `Q.packId` とエリア設定を差し替えると同じエンジンで遊べる。

## 著作権について
世界観・モンスター・名前・ドット絵・音はすべてオリジナル。ポケモンの名前・デザイン・音楽・マップは使っていない。
問題文もCisco公式問題や問題集の写しではなく、試験範囲に沿って新規に作成したもの。
